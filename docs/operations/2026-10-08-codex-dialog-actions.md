# Codex 连接弹窗的操作按钮被挤出屏幕

手机截图中已经选中一个 Windows thread，但没有看到“连接并打开”。按钮仍存在，只是弹窗整体和内部列表分别滚动，内部列表又固定占用 `50vh`。标题、说明、筛选、列表和加载更多叠加后，底部操作超出可见区域。较大字号下，用真实组件复现时，按钮底部坐标达到 989 CSS px，视口仅有 844 px。

修复将弹窗分成不收缩的标题、可收缩且独立滚动的中间内容、不收缩的操作栏。取消列表的独立滚动和半屏高度，补页触发绑定到中间内容容器。按钮在小屏和大字号下可以换行；布局沿用 Dialog 已有的 visualViewport 高度与偏移，并保留安全区间距。选择校验、机器绑定、请求生命周期和实际连接逻辑未改。
